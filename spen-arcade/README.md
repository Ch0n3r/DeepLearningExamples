# S Pen Arcade

Сборник мини-игр, управляемых **наклоном стилуса Samsung S Pen в воздухе**.

## Главное про архитектуру

AI Studio генерирует веб-приложение. S Pen SDK — нативный Android. Поэтому
проект разрезан на два слоя:

```
┌─────────────────────────────────────────────────────┐
│  Android (Kotlin)                                   │
│  ├─ SPenRemote SDK ──► air motion (дельты углов)    │
│  ├─ MotionEvent    ──► hover tilt (абсолютный угол) │
│  └─ SPenBridge ──@JavascriptInterface──┐            │
└────────────────────────────────────────┼────────────┘
                                         ▼
┌─────────────────────────────────────────────────────┐
│  WebView: игра (TypeScript + Canvas2D)              │
│  PenInput ──► PenState {tiltX, tiltY, button, ...}  │
│     ▲ фолбэки: PointerEvent / гироскоп / мышь       │
│  Engine (fixed timestep) ──► Scene                  │
│     ├─ Hub · SkyDrifter · TiltRacer                 │
│     └─ BirdHunt · InkRunes                          │
└─────────────────────────────────────────────────────┘
```

Игровой код **никогда** не обращается к SDK напрямую — только к `PenState`.
Поэтому весь геймплей отлаживается прямо в браузере AI Studio (мышь/гироскоп),
а на телефоне просто подменяется источник ввода.

## Ключевой нюанс S Pen SDK

`AirMotionEvent` отдаёт **только дельты** угловой скорости (`deltaX`/`deltaY`
в градусах за тик). Абсолютного наклона в воздухе не существует — гироскоп
в пере не знает, где «ноль». Отсюда два решения в `SPenBridge.kt`:

1. **Leaky integrator** — дельты интегрируются в виртуальный угол, который
   постоянно утекает к нулю (55% в секунду). Управление получается
   самоцентрирующимся: отпустил — вернулось в нейтраль.
2. **Complementary fusion с hover** — когда перо подносят к экрану,
   `MotionEvent.AXIS_TILT` даёт честный абсолютный угол, и накопленный
   дрейф гироскопа сбрасывается.

## Мини-игры

| Игра | Наклон | Кнопка стилуса | Что внутри сложного |
|---|---|---|---|
| **Sky Drifter** | курс и тангаж самолёта | форсаж с перегревом | процедурный каньон из fbm-шума, сужающийся с дистанцией |
| **Tilt Racer** | руль; от себя — газ | ручник (занос) | дрифтовая физика с раздельным трением вдоль/поперёк корпуса |
| **Bird Hunt** | ведёт прицел (ускорение) | тап — дробь, удержание — перезарядка | boids-стая с паникой, continuous collision для дроби |
| **Ink Runes** | рисует руну в воздухе | зажать = писать | распознаватель жестов $1 Unistroke |

## Самые нетривиальные места в коде

- `web/src/input/OneEuroFilter.ts` — адаптивный фильтр: жёстко сглаживает
  дрожь руки в покое и почти отключается при резком движении. Обычный
  low-pass пришлось бы выбирать между тремором и лагом.
- `web/src/input/PenInput.ts` — порядок обработки: снять смещение калибровки →
  фильтр → мёртвая зона → экспонента. Любая другая очередь даёт либо рывок
  на выходе из дедзоны, либо неустранимый дрейф.
- `web/src/core/Engine.ts` — фиксированный шаг 1/60 с накопителем. Без него
  физика наклона на 120-герцовом Galaxy ведёт себя иначе, чем на 60-герцовом.
- `web/src/core/GestureRecognizer.ts` — $1 recognizer: ресемплинг по длине
  дуги, поворот по индикативному углу, поиск лучшего угла золотым сечением.
- `web/src/core/math.ts` — `SpatialHash` (broad-phase O(n) вместо O(n²)) и
  `segmentHitsCircle` (дробь за кадр пролетает 25 px и иначе протыкает птицу).
- `android/.../SPenBridge.kt` — слияние двух разнородных каналов ввода:
  относительных дельт из `AirMotionEvent` и абсолютного угла из hover.

## Запуск

Веб-часть (разработка и AI Studio):
```bash
cd web && npm install && npm run dev
```
Мышь двигает наклон, пробел — кнопка стилуса.

APK: см. `android/SETUP.md` — сборка через GitHub Actions одной кнопкой.
Samsung S Pen SDK уже лежит в `android/app/libs/`, скачивать ничего не нужно.

## Промпт для Gemini в AI Studio

`AI_STUDIO_PROMPT.md` — готовый текст, который нужно вставить в
aistudio.google.com/apps, чтобы Gemini доработал визуал и контент поверх
этой архитектуры, не сломав слой ввода.
